# Motion assets

These files are copied without image modification from the same project repositories linked in the portfolio. They retain the source projects' asset attribution; their inclusion does not assert that Zhehan drew the source artwork.

- `skytiles.png`: [SkyTiles tilesheet](https://github.com/siempre-2004/SkyTiles_VisualStudio/blob/main/Source/tilesheet_packed.png).
- `prairie-tiles.png`: [EcoSystem tiles and sheep](https://github.com/siempre-2004/EcoSystem_VisualStudio/blob/main/playground/data/tiles.png). Sheep frames use the source project's 50 × 30 region at y = 60.
- `wolf.png`: [EcoSystem wolf](https://github.com/siempre-2004/EcoSystem_VisualStudio/blob/main/playground/data/wolf.png).

`ambient.js` draws small decorative motion studies with these sprites. This is a website animation, separate from the original games' simulation code. The existing terrain and fragment collection game remain in `world.js`.
