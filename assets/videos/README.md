# Project footage

`echoes-of-silence-demo.mp4` is the first 3 minutes 04 seconds of the user-provided
`Group1 - Degree Project Video Documentation.mp4`.

The clip keeps the original 1920 × 1080 H.264 video and AAC audio streams without
re-encoding. Its MP4 metadata is placed before the media data for web playback.
The page uses native playback controls, inline playback, and metadata preloading;
it does not autoplay. The poster (`assets/projects/echoes-video-poster.webp`) is the original video frame
at 1:15, scaled proportionally to 1600 × 900.
