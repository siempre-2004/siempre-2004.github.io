00 / 项目概览

基于 raylib 的 C++ 瓦片渲染原型。我实现不同规模的地图读取与切换、相机控制、可见性剔除和瓦片重排，用可操作的画面检查地图与视野之间的关系。

项目范围
基于 raylib 的技术原型
地图规模
32×32 / 128×128 / 1024×1024
实现重点
地图数据、相机范围与可见性

相机锁定与地图切换

地图大小变化时，观察区域也需要重新约束。C 键切换范围锁定，锁定状态会跨地图切换保留，再按一次 C 才解除。

相机范围的两种观察状态

原素材中按 C 前后的画面展示了相机范围操作，以及相机与地图位置之间的关系。

03 / C++ / raylib / 图形技术原型

可以直接验证的功能

通过相同的操作检查不同地图规模下的行为，观察地图数据、相机范围与绘制结果怎样相互影响。

操作功能
Tab在小地图与大地图之间切换
R切换到 128×128 的中地图
F / G切换相关开关并执行可见性剔除
C锁定或解除相机范围
Space重新分布瓦片位置
