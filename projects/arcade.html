01 / 自制控制器 / Unity + Arduino

实体动作怎样进入游戏

装置把玩家的手部操作变成可识别的输入，再交给 Unity 触发角色或任务中的动作。颜色传感器用于识别收集任务中的目标。

  1. 01操作钓竿与装置
  2. 02传感器读取
  3. 03Arduino 处理
  4. 04串口传给 Unity
  5. 05触发游戏动作
02 / 自制控制器 / Unity + Arduino

从输入想法到可用装置

输入方式经过探索和调整：早期用摄像头与钓鱼装置尝试控制角色，之后接入颜色感应与 Arduino。计划中的 DancePad 没有进入最终方案。

01

先验证动作

从玩家实际拉动、移动装置的动作出发，尝试把实体操作与游戏里的行为对应起来。

02

再连接输入

编写传感器与 Arduino 相关代码，把装置读数接入 Unity，并检查输入与角色反馈是否对应。

03

放回完整流程

把输入与移动、文字提示、场景切换和收集任务接起来，使装置操作成为游戏流程的一部分。

03 / 自制控制器 / Unity + Arduino

团队完成的游戏循环

村庄潜行和屋内收集构成一轮夜间行动，玩家需要在路线规划、限时操作和物品管理之间切换。

01

穿过村庄

观察巡逻守卫和视野范围，选择路线，避免被发现。

02

进入收集任务

进入房屋后切换任务场景，在有限时间内收集指定颜色组合；正确操作提供 LED 反馈，错误会减少可用时间。

03

回到行动流程

场景切换、物品状态与提示把潜行和收集连接起来，让玩家知道目前的目标。

04 / 自制控制器 / Unity + Arduino

我具体做了什么

01

装置输入与交互逻辑

接入 Arduino 传感器输入，编写与调试 Unity 中的相关交互，并探索装置控制角色的方法。

02

文字与场景流程

制作文字交互与提示，连接任务、物品管理和场景切换，让实体操作得到游戏中的回应。

03

原创音乐

使用 Logic Pro 为游戏创作轻快的钢琴音乐。
