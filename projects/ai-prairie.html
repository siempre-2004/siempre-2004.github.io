00 / 项目概览

使用 C++ 和 raylib 制作的个人项目。羊觅食、逃跑和繁殖，狼寻找并追逐目标，草地生长与恢复；玩家通过牧羊人和地图编辑影响这个持续变化的小世界。

01 / C++ / 自主智能体 / 可编辑地图

先看清这个世界怎样运转

同一张地图中，每个实体根据状态与周围环境行动。它们之间的影响组成可观察的生态循环。

01

羊

在游荡、吃草、逃跑和繁殖等状态之间切换。发现狼后改变目标，重新寻找安全路线。

02

狼

寻找羊并沿路径追逐，也会与牧羊人发生交互。

03

草与牧羊人

草被吃掉后重新生长，粪便促进生长；玩家控制牧羊人移动，干预局部环境。

02 / C++ / 自主智能体 / 可编辑地图

状态机决定“现在做什么”

FSM 把行为拆成清楚的状态和切换条件。饥饿、周围目标与威胁变化时，实体切换状态，再更新移动目标。

  1. 01读取自身与周围状态
  2. 02判断切换条件
  3. 03确定当前行为
  4. 04选择目标
  5. 05执行与更新
03 / C++ / 自主智能体 / 可编辑地图

A* 解决“怎么走过去”

状态机选择目标，寻路模块计算路线。羊、狼和牧羊人使用地图上的可行走信息，目标或地图变化时更新路径。

01

比较候选节点

用 f = g + h 综合已经走过的成本与到终点的估计成本，选择下一步搜索的节点。

02

记录与回溯

记录父节点；找到终点后回溯路径，交给实体逐步移动。

03

变化后重算

玩家修改地形，或智能体转向新目标时，重新计算可行路线。

04 / C++ / 自主智能体 / 可编辑地图

让运行中的规则看得见

调试模式显示网格和路径，实体检查显示当前属性，编辑模式可以改变地形。这些工具用来检查行为为何发生，也便于继续调整生态规则。

操作功能
F1切换调试显示
F2切换观察与编辑模式
左键 / Left click设置牧羊人目的地
右键 / Right click观察模式检查实体；编辑模式修改地图
