01 / 几何处理 / Python / 优化基线

把编辑目标变成优化条件

把需要移动的曲线作为目标，同时控制周围表面的变形方式。当前实现每次为输入求解顶点位置。

  1. 01设定目标曲线
  2. 02计算几何误差
  3. 03约束边界与平滑性
  4. 04优化顶点位置
  5. 05查看变形结果
01

曲线误差

让网格中的曲线接近用户设定的目标曲线。

02

边界漂移

限制外围顶点的移动，减少局部编辑对远处区域的影响。

03

位移平滑

约束相邻区域的位移变化，避免表面出现过于突兀的变化。

02 / 几何处理 / Python / 优化基线

目前做到哪里

当前使用平面网格和固定曲线索引，便于先检查优化过程。真实网格导入、把自由笔画映射到表面、按测地距离选取局部区域，以及学习式位移预测，都是后续方向。

01

已有基线

逐实例优化顶点位置；通过 Streamlit 调整参数并旋转 3D 视图。

02

后续评估

在接入真实网格后比较局部形状保持与交互延迟，再评估新的求解方式。
